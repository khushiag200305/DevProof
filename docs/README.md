# DevProof documentation

| Document | What it covers |
|---|---|
| [architecture.md](architecture.md) | System diagram, backend structure, how an analysis runs, data model |
| [scoring.md](scoring.md) | Evidence kinds, scoring weights, thresholds, worked example |
| [features.md](features.md) | Every feature by role, with the rules behind it |
| [api.md](api.md) | All REST endpoints and who may call them |
| [ci-cd.md](ci-cd.md) | GitHub Actions checks and deployment to Vercel and Render |

The diagrams are written in [Mermaid](https://mermaid.js.org), which GitHub draws automatically
when you open the file. To use one in the report, open the file on GitHub, or paste the code block
into [mermaid.live](https://mermaid.live) and export it as PNG or SVG.

Live app: https://dev-proof-mu.vercel.app
