# site

DevProof's project website: one static page (`index.html`) with screenshots in `img/`. It links
to the live app (https://dev-proof-mu.vercel.app), the repository and the documentation.

It is published with GitHub Pages by `.github/workflows/pages.yml` whenever `site/` changes on
`main`, at **https://khushiag200305.github.io/DevProof/**.

One-time setup: repository **Settings → Pages → Build and deployment → Source: GitHub Actions**.

To preview locally, open `site/index.html` in a browser. The screenshots use fictional example data.
