## What the prototype demonstrates
- Resume upload and skill/GitHub extraction
- GitHub repository retrieval for a candidate
- Technology fingerprint detection for the initial supported skill set
- (If ready) preliminary evidence scoring

## How to run it
See the root [README](../README.md#run-locally) for backend/frontend setup.

## Demo flow
1. Upload a sample resume PDF.
2. Show extracted skills and GitHub link.
3. Show retrieved repository evidence for one or two claimed skills.
4. Show the resulting classification (or raw signals if scoring isn't wired up yet) and the reasoning behind it.
